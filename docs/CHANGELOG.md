### 實際驗證
- 建置首頁及兩篇講義成功；3 個生成頁面與原稿／模板一致，51 個本機連結、資產與錨點通過檢查。
- 新增欄位檢查：三層提示、每問一份四段式擬答、至少四項自評、變化題擬答及引用與本篇來源對應。
- HTML 檢查：每篇主題與變化題各有作答欄位及檢討區；欄位標籤有效，提示與答案預設收合。
- 第一篇瀏覽器實測：初始兩個檢討區皆隱藏；空白作答受阻並顯示提示；輸入草稿後可開啟主題檢討，提示與擬答仍保持收合；三層提示可獨立查看，擬答可展開；自評可勾選。
- 第一篇變化題實測：未作答仍受阻，不因主題完成而解鎖；勾選紙本完成後才開啟，變化題擬答仍須另外展開。
- 第二篇實測：紙本完成路徑可開啟主題檢討；主題兩問解析可查看；變化題可用文字草稿獨立開啟，擬答可用 Enter 展開。
- 手機窄螢幕（內容視窗 375px）與桌面（1265px）均無整頁橫向溢出；已檢查案例題與展開解析畫面。檢查時瀏覽器未回報 error／warn 訊息。
- 案例預覽截圖保存於本機 `preview/案例練習_桌面.jpg`、`preview/案例練習_手機.jpg`，不包含在上傳包。
- 列印改為保留案例題目前的鎖定與展開狀態，避免自動露出擬答；尚未實測列印輸出及停用 JavaScript 模式。
- 已更新完整專案 ZIP，GitHub 上傳與公開仍依使用者決定暫緩。

### 使用限制
- 完成確認僅檢查非空白草稿或紙本勾選，不能判定論證是否完整正確；本站不自動批改或給分。
- 草稿不傳送、不儲存，離開或重新整理前須自行複製保留。
- 新增擬答尚未經法律專業人士審訂。
