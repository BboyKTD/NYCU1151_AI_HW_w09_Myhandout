# 第九週作業繳交說明

繳交標題：`學校 學號 系級 姓名 民法總則學習講義網站`

請自行補入實際個人資訊，勿將學號等資料直接加入公開網站。

## 1. 專案簡介

本專案為台灣民法總則初學者製作一個可持續擴充的學習講義網站。首批示範主題為「行為能力」及「意思表示」，每篇包含學習目標、概念解說、規則整理、虛構教學例子、常見混淆、自我檢核、申論案例練習及官方法條來源。申論採先完整作答再檢討，提供三層提示、四段式參考擬答、自評清單及變化題。

本次的重點是透過與 AI 討論，建立 `AGENTS.md`，明確約定內容格式、網站風格、資料命名、來源查核、新增頁面流程與驗收條件；讓 AI 之後能沿用同一套方法繼續工作。

## 5. 規則如何幫助 AI 繼續完成？

若之後要新增「代理」講義，AI 先讀取 `AGENTS.md`，便能知道目標讀者、法律來源、固定章節、題目形式、檔名與放置位置。AI 只需新增一份講義 JSON 原稿，依規則查核官方法條、填入摘要、自我檢核及申論案例；申論必須包含設問、三層提示、逐問四段式擬答、自評及單一事實變化題。建立雙向相關連結後執行建置，就會產生風格一致的新頁面，首頁也自動增加對應的講義卡片。

共用模板集中管理版面，樣式與互動也只維護一份。檢查工具能發現欄位缺漏、答案索引錯誤、未更新的生成檔，以及失效的本機連結；法條正確性與實際閱讀品質仍需進一步審閱。這套規則讓新增內容有可重複的流程，而不只是完成一次性的網頁。
