# 民法總則學習講義網站

第九週「換你當老闆」作業：透過 `AGENTS.md` 定義可重複使用的內容、視覺、檔案與驗收規則，讓 AI 能沿用同一套方式繼續新增講義。

## 已有成果

- 首頁 `index.html`：講義清單、主題／條號搜尋與閱讀方法。
- `lessons/capacity.html`：行為能力、法定代理人允許與契約效力。
- `lessons/declaration.html`：意思表示生效時點、撤回與撤銷的區別。
- 每篇提供學習目標、概念、規則、虛構教學例子、常見混淆、3 題互動檢核、官方來源及相關講義。
- 每篇另有一組自編申論案例：完整作答區、三層提示、逐問四段式參考擬答、自評清單與單一事實變化題。
- 兩篇原稿沿用同一個模板產生；新增內容只需填寫一份 JSON 並建置，首頁自動更新。

## 目錄

```text
AGENTS.md                 AI 接手專案時的工作規則
index.html                生成的首頁（GitHub Pages 入口）
lessons/*.html            生成的講義，可直接靜態瀏覽
assets/style.css          共用視覺與手機／列印樣式
assets/site.js            搜尋、題目回饋、列印
content/lessons/*.json     可編輯的講義原稿與來源
templates/*.html          共用首頁／講義模板
scripts/build.py          建置頁面與目錄，僅使用 Python 標準函式庫
scripts/check.py          檢查來源結構、生成一致性及本機連結
docs/                     繳交說明、實際協作與驗證紀錄
```

## 本機閱讀與修改

直接開啟 `index.html` 即可閱讀；搜尋與題目使用本機 JavaScript，沒有後端或 API key。

修改原稿／模板後，在專案根目錄執行：

```sh
python3 scripts/build.py
python3 scripts/check.py
python3 -m http.server 8090 --bind 127.0.0.1
```

開啟 `http://127.0.0.1:8090`。核心內容在停用 JavaScript 時仍可閱讀，題目可透過「查看答案與解析」自行核對。

## 案例練習方式

從講義的「案例練習」章節進入，先讀題並完整作答（建議約 12 分鐘）。在頁面輸入草稿，或勾選已在紙本／其他地方完整作答，再按「我已完成作答，開啟檢討」。三層提示、參考擬答及自評清單各自收合，由讀者選擇何時查看。

每份擬答依「問題 → 法律依據與要件 → 套用事實 → 結論」撰寫。變化題只改一項關鍵事實，另設作答區與完成確認，練習指出判斷如何改變。本站不會自動批改申論或給分；擬答為 AI 協作教學內容，非教授原擬答。

草稿只存在目前頁面，未送出或儲存，離開／重新整理前請自行複製。停用 JavaScript 時可直接用原生展開區閱讀檢討，須自行先完成作答。列印會保留案例題當下的鎖定及展開狀態，尚未開啟的擬答不會因列印自動展開。

## 如何讓 AI 新增一篇

先讓 AI 讀 `AGENTS.md`，再交辦：

> 請依 AGENTS.md 新增「代理」入門講義。查核全國法規資料庫當時現行條文，沿用既有內容結構、視覺、自我檢核與案例練習形式，附三層提示、逐問四段式擬答、自評清單及單一事實變化題；和適合的既有講義建立相關連結。建置並檢查首頁、新頁及舊頁，回報查核日期、變更檔案與尚未驗證項目。這次先完成本機成果，不發布。

AI 應新增 `content/lessons/agency.json`，填入未占用的 `order`，更新雙向 `related`，再執行建置。無須手改首頁卡片或複製整套 CSS。

## GitHub Pages 發布

目前依使用者要求，先交付本機成果，尚未上傳或公開。

1. 在自己的 GitHub 帳號建立一個公開 repository，例如 `civil-law-study-notes`。
2. 只上傳**本資料夾內**的專案檔案；讓 `index.html`、`AGENTS.md` 位於 repository 根目錄。保留 `content/`、`templates/`、`scripts/`、`docs/` 等原稿與規則，不只上傳生成頁面。
3. 到 repository 的 **Settings → Pages**，選擇從分支部署（Deploy from a branch），以 `main` 的根目錄 `/ (root)` 為來源並儲存。介面名稱可能隨 GitHub 更新；以當時畫面為準。
4. 等待部署完成，使用 GitHub 顯示的正式網址。實際開啟首頁與兩篇講義，確認搜尋、作答與相關連結正常。
5. 把 repository、網站與 `AGENTS.md` 的實際網址填入 `docs/作業繳交說明.md`。目前文件沒有冒充已發布的連結。

此站使用相對路徑，支援 `https://帳號.github.io/儲存庫名稱/` 的專案子路徑。公開資料夾裡沒有身分資料、帳號密鑰、課程逐字稿或其他週的教材。

本專案不需要外部套件、追蹤工具或登入。未設定自動定期更新法條；修改法律內容時須重新查核來源。
